API testing basics

POSTMAN CONCEPTS

What is an API?

An API allows two software systems to communicate. Testers check requests, responses, status codes, data and error handling.

Common HTTP methods

  • GET — retrieve information
  • POST — create a resource
  • PUT — replace or update a resource
  • PATCH — partially update a resource
  • DELETE — remove a resource

Common status codes

  • 200 — OK
  • 201 — Created
  • 400 — Bad Request
  • 401 — Unauthorized
  • 404 — Not Found
  • 500 — Internal Server Error

Automation testing

NEXT LEVEL

What is automation testing?

Automation testing uses scripts and tools to execute repeatable checks. It is useful for regression testing and repetitive workflows.

Learning sequence

  1. Learn basic programming with JavaScript, Java or Python.
  2. Understand locators, assertions and waits.
  3. Learn Playwright or Selenium.
  4. Automate a login and search workflow.
  5. Run tests and review reports.

Example: Playwright test

import { test, expect } from '@playwright/test';\ntest('page has title', async ({ page }) => {\n  await page.goto('https://example.com');\n  await expect(page).toHaveTitle(/Example/);\n});

This is example code for learning. It requires a Playwright project to execute.
